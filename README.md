# Kisha Dua — I have a spilling problem.

Portfolio of Kisha Dua, visual communication designer (Mumbai · Delhi).

## Structure
- `index.html` — the whole site (homepage, The Spiller, The Spills, case studies, The Overflow, Say Hello).
- `assets/work/` — case-study images and the Nazariya logo video.
- `.nojekyll` — tells GitHub Pages to serve the files as they are.

## Updating
- **Swap a case-study image:** replace the file in `assets/work/` with a new one of the **same name** (e.g. `bm_05.jpg`), then commit.
- File names follow the case-study order: `nz_` Nazariya, `bm_` Bare Minimum, `od_` Lives on Hold, `a6_` After6; `_cover`, `_01`, `_02`…
